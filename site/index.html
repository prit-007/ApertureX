v0.3.5 — Oct 31, 2026 ▾
  • Targeted Output Sharpening: Medium-specific unsharp mask (Screen, Print Matte, Print Glossy, Web) with independent radius, halo suppression, and strength separate from capture sharpening.
  • Upright Auto-Geometry: Sobel gradient line detection automatically detects vertical divergence and levels perspective distortion.
  • Auto Mask (Edge-Aware Brush): Euclidean color contrast boundary gating prevents brush strokes from bleeding across subject edges.
  • Depth Range Mask: Sliced 3D depth isolation with feathered transitions using embedded GDepth or monocular depth estimation.
  • Skin-Aware Auto Tone: Preserves natural human complexions, computes percentile histogram recovery (p99/p99.9 highlights, p1/p0.1 shadows), and applies smart vibrance.
  • Smart Collections: Dynamic multi-rule catalog query engine (ratings, flags, ISO, focal length, aperture, shutter speed, cameras) with instant presets.
  • 64-bit Perceptual Duplicate Detection: Gradient dHash fingerprinting and Hamming distance clustering for duplicate and burst culling.
  • Photo Quality Culling: Laplacian variance blur scoring and YuNet facial landmark eye openness analysis.
  • Folder Watching & Auto-Import: Debounced background directory watcher for tethered ingest and desktop drops.
  • Pro Print Studio: Multi-up contact sheets, printer ICC profile soft-proofing, page layouts, and high-DPI PDF export.
  • Video Color Studio: Video trimming and playback with unified 3D LUT grading engine.
  • Studio Camera Tethering: Sony, Canon, and Nikon PTP/IP and USB tethered shooting with live capture.
  • Color Engine Precision: Strict zero-division guards in auto-tone percentile luminance scaling.
  • Memory Safety: Edge-aware brush contrast masks run in Rust zero-copy scratch buffers without heap allocations.
v0.2.4 — Oct 20, 2026 ▾
  • YuNet face detection: 12-head MIT model with greedy NMS and largest-face auto-subject placement.
  • On-device AI runtime: optional U²-NetP subject masks and depth through ONNX Runtime Mobile with NNAPI/CoreML hooks.
  • Color-range masks: HSV hue, saturation, and luminance bands with softness and an eyedropper.
  • 16-bit TIFF export: uncompressed 16-bit-per-channel output with the full edit baked in.
  • Embedded GDepth blur: parses JPEG XMP depth maps, aligns them through flip/rotate/crop, and drives lens blur.
  • Android 16 native crash: ORT 1.24.3 fixes the arm64 SIGSEGV during U²-NetP inference.
  • Hard-crash observability: native SIGSEGV/SIGABRT/ANR exits now produce a next-launch crash report.
  • AI fallbacks are logged: subject-mask and depth failures now reach the in-app JSONL log.
  • Auto Tone now applies temperature and tint alongside tonal adjustments.
v0.2.3 — Oct 19, 2026 ▾
  • Film and slate UI refinements, compact accordion bottom sheets, and an Auto Tone action.
  • ML background blur, Ruby Peeks toggle, true-source compare view, and wired film sliders.
  • Original-bytes EXIF inspection and a prominent per-task model router.
v0.2.0 — Oct 17, 2026 ▾
  • Look QR Code Open Standard: Encode complete non-destructive edit recipes into scannable offline QR creator cards with zero cloud dependencies.
  • Pure-FOSS Offline QR Engine: High-performance Rust rxing camera decoder running in compiled memory with zero closed Google Play Services / Firebase blobs.
  • Pat David Analog Film Simulation Core: Bundled open-source profiles for Kodak Portra 400, Fuji Pro 400H, Ilford HP5, and Cine Teal & Orange in <0.05MB JSON recipes.
  • Community Preset Hub: Decentralized preset repository powered by public GitHub repos with in-app previews and one-tap import.
  • C2PA Content Credentials: On-device cryptographic provenance generator (c2pa.rs) embedding verifiable digital authorship and edit transparency manifests into exported JPEGs.
  • Universal Preset Translation Engine: Two-way conversion between Adobe XMP (.xmp), .lrtemplate, 3D LUT (.cube), and HALD CLUT PNGs.
  • Export Branding & Watermark Engine: Native Rust watermark renderer supporting custom photographer signatures, EXIF stamps, and FOSS badges.
  • Zen 6-Master Tab Bar: Clean progressive disclosure organizing Light, Color, Blur, Effects, Detail, and Geometry with deep sub-menus.
  • Wiper Split-Curtain & History Tree: Smooth interactive comparison curtain and non-destructive snapshot history tree.
v0.1.0 — Oct 16, 2026 ▾
  • First public release: Dual-UI shells (Lightroom-style precision panel + Snapseed gesture mode).
  • Native Rust engine: 65³ 3D LUT generation in <1ms, tile viewport memory budget up to 200MP.
