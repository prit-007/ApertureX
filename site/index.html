Studio-Grade Capabilities

Engineered for creators who value craftsmanship

ApertureX bridges desktop precision and mobile fluidity without proprietary tracking, subscription paywalls, or privacy loss.

Dual UI Shells, One Recipe

Lightroom-style precision instrument tray for calibrated slider tweaking, and Snapseed-style gesture shell for edge-to-edge painting. Switch anytime without interrupting edits.

Zero Desync

High-Performance Rust Core

Raw demosaicing, matrix transformations, spatial denoise, lens optics, and mask arithmetic run in compiled Rust over memory-safe FFI boundaries with zero garbage collector pauses.

rust_lib_aperturex

Tile Viewport (200 MP)

Edit medium-format and 200MP phone photos smoothly without out-of-memory crashes. The tile compositor allocates level-0 high-zoom tiles into a strict 512MB LRU device budget.

LRU Tile Cache

120 FPS GPU Preview

Real-time slider scrub feedback generates a 33×33×33 3D LUT atlas in under 1ms, sampled directly by Flutter's Impeller fragment shader. No frame drops, pure tactile response.

Impeller Fragment Shader

Classical Auto-Straighten

Hough line orientation voting algorithm analyzes proxy gradients and detects tilted horizons instantly. One-tap alignment with 0.1° accuracy without neural model weight bloat.

Hough Voting

Embedded Depth & Lens Blur

Extracts calibrated Google GDepth and Apple disparity metadata from JPEG containers for optical bokeh simulation, with customizable 5/6/7/9-blade iris shapes and specular highlight boost.

GDepth / XMP

Precision Local Masks

Stack brush, linear, radial, and raster bitmap masks. Features palm rejection, stylus pressure-sensitive flow mapping, inverted subject/background targeting, and ruby heatmap overlays.

Stylus & Palm Rejection

XMP Sidecars & LUT Import

Import third-party .cube 3D LUTs and Adobe Lightroom .xmp develop presets. Non-destructive edits write standard crs:XMP sidecars alongside photos so you never get locked into an ecosystem.

Open Standards

The photo is the hero: never suffocate the canvas

Unlike amateur apps where bottom sheets slide up to cover 80% of the screen, ApertureX guarantees that the photo occupies 75–80% of portrait height, completely unobstructed. Tool controls live docked in the natural thumb reach zone.

Edge-to-Edge Masking

Pro Pen precision & hardware palm rejection

Switch to the Snapseed shell for gesture-first editing. Paint local adjustments with a pressure-sensitive stylus (Apple Pencil / S-Pen), while touch gestures remain locked to zoom and pan.

Stylus Device Filtering Touch inputs are strictly rejected during brush strokes to eliminate accidental thumb marks.
Ruby Heatmap Overlay Active mask layers glow in ruby red so you see precisely which highlights, shadows or figures are targeted.
Zero-Loss Export

Banded memory processing with XMP sidecars

Exporting a 100MP image requires gigabytes of memory if processed in a single buffer. ApertureX breaks images into streaming bands processed by Rust, keeping RAM usage capped under 512MB.

Banded Resampling & Seamless Stitching Bilinear raster masks and spatial filters stitch with zero seams across bands.
Lightroom-Compatible .xmp Metadata All curves, color wheels, and crop geometry write into open XMP standards alongside exported images.

Under the Hood: Pure Rust Core & Flutter Viewport

Decoded image data lives resident in Rust native heap memory. Edits manipulate a lightweight Dart recipe object with 0ms sync latency.

65³ 3D LUT Atlas
