Privacy

Enforced offline, not just promised

ApertureX has no accounts, no servers, no telemetry. A guard test — offline_guard_test — runs in CI and fails the build if a network or analytics package is ever added to pubspec.yaml.

Why ApertureX

Pro-grade editing, built as free software

Dual UIs, One Recipe

Lightroom-style precision panels (default) and a Snapseed-style gesture shell — switch any time; the edit never changes.

Rust Engine

Color pipeline, geometry, spatial ops and masks run in Rust over FFI — one grading path shared by preview and export.

Tile Viewport

48–200 MP photos edit as tiles with an LRU byte budget — no out-of-memory crashes, no giant bitmaps.

60 fps Preview

Proxy-resolution decode, split base/grade bakes and one baked 65³ LUT sampled by an Impeller fragment shader.

Full-Res Export

Banded full-res export with progress and cancel, EXIF carry-over, plus Lightroom-style XMP sidecars so nothing locks in.

Crop & Geometry

Aspect presets, rotate/flip/straighten with GPU warps for instant feedback and a CPU resampled final export.

Local Masks

Brush, linear and radial masks with pressure-sensitive stylus input, palm rejection and a non-destructive mask stack.

Presets & Batch

Import .cube LUTs and Lightroom .xmp presets, save looks, batch paste and export across a date-grouped gallery.

02 — Lightroom Shell

Precision sliders, live histogram

The default panel shell exposes the full color pipeline — exposure, WB, tone curves, HSL, split-tone, clarity — with every change re-baking the preview LUT at interactive rates.

  • Baked 65³ LUT means grading costs one shader sample per pixel
  • Undo/redo across every operation, nothing is ever baked in early

03 — Snapseed Shell

Brushes, masks, gestures

The gesture shell puts masking at your fingertip: paint with a stylus and get pressure-mapped flow, reject palms automatically, stack brush/linear/radial masks non-destructively.

  • Stylus pressure drives brush opacity and flow
  • Mask stack with per-layer visibility — like Lightroom's local tabs

04 — Export

Full resolution, banded, cancellable

One Rust call exports in bands with determinate progress — EXIF and ICC handled, XMP sidecar optional — then shares through the system sheet.

  • Preview == export: the grading math lives once, in Rust
  • Progress polls a native cell — no Dart/Rust roundtrip storms
